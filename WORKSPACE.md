# Firstmate

## Working layout

* `bin/` - shell entrypoints and legacy automation
* `tools/firstmate_orchestrator/` - Windows-oriented Python orchestrator helpers
* `tests/` - repository tests
* `docs/` - documentation

## Editing rule

* Make commit-worthy source changes in the repository tree.
* Treat `C:\Developer` as scratch space for disposable copies and experiments.
* Keep orchestration helpers under `tools/` so they stay versioned with the project.
